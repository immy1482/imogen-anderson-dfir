## Core Concepts Covered

### 1. What is OWASP?
The **Open Worldwide Application Security Project (OWASP)** is a non-profit foundation dedicated to improving software security. It serves as a primary open-source resource for developers, penetration testers, and security analysts regarding web application vulnerabilities.

### 2. The OWASP Top 10 (2021)
The OWASP Top 10 is a regularly updated list outlining the 10 most critical security risks facing web applications:
1. **A01:2021 – Broken Access Control**
2. **A02:2021 – Cryptographic Failures**
3. **A03:2021 – Injection**
4. **A04:2021 – Insecure Design**
5. **A05:2021 – Security Misconfiguration**
